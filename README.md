# Tidewater Runtime Gateway

Batching and request-routing gateway for Meridian inference services.

## Distribution status

Released - stable channel. Public distribution approved by the toolkit maintainers.

## Layout

- `src/tidewater/gateway.py` - request router
- `tests/test_gateway.py` - unit tests
- `dist/manifest.json` - last build record produced by the build service

See `docs/usage.md` for configuration notes.
